Files in. Markdown out.

Convert Word, PDF, PowerPoint, Excel, EPUB, HTML, CSV and more to .md. Add as many files as you like, then download them one by one or all together. Everything runs in your browser, so nothing is uploaded.

docx · pdf · pptx · xlsx · xls · csv · tsv · html · epub · json · xml · ipynb · txt · zip

    What’s supported

    This page follows the output style of Microsoft’s MarkItDown (headings, lists, tables and links kept as Markdown) using browser libraries, because MarkItDown itself is a Python package. ZIP archives are converted file by file into one document. Images, audio, YouTube links and old .doc/.ppt files aren’t supported here: they need OCR, speech-to-text or Python-only converters.
